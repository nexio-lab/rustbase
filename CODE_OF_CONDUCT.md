# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc], in full.

By participating, you agree to uphold it.

To report a concern, open a private contact channel with a maintainer
(see [SECURITY.md](SECURITY.md) for the security-disclosure path, which
doubles as the private contact channel for conduct issues until a dedicated
one is set up).

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
